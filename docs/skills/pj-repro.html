pj-repro

Reproduces a bug with a failing test before the fix.

Input#issue (a bug)
RequiresThe issue has spec-ready.
ResultA failing test on the implementation branch. Then pj-implement continues.

Steps

  1. Read the issue, its comments, and its attachments. See Trust.
  2. Claim the issue, and create the worktree .worktrees/<n> on the branch pj/<n>. See Claim. Install the dependencies.
  3. Write a test that fails for the reported reason.
  4. Run the test. Make sure that it fails for the correct reason, not for a setup error.
  5. If the bug does not reproduce: comment on the issue with what you tried and a stopped marker, and stop. Do not change the labels.
  6. Commit the test as its own commit.
  7. Save the test output to attachments at issues/<n>/evidence/.
  8. Continue with pj-implement in the same worktree.

Devlog

At the end of the run, append one entry to the devlog. Also append one if the run stops early.
