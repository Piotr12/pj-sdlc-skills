pj SDLC skills

Agent skills that take a GitHub or Forgejo issue from spec to a merged PR. Version 0.2.0 has ten skills. All of them follow one protocol: skills/pj-prep-the-repo/reference/protocol.md.

Skills

SkillDoes
pj-prep-the-repoSets up labels, the attachments branch, rulesets, the scripts, AGENTS.md, and configs through a PR.
pj-grill-for-specs-readinessChecks an issue against the Definition of Ready and builds the spec.
pj-implementImplements a spec-ready issue and opens a PR.
